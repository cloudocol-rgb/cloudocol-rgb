# Images

Drop brand and social assets here.

Expected files:

- `cloudocol-mark.svg` — the logo mark used in the header and footer
- `og-image.jpg` — 1200x630, for Open Graph and Twitter cards
- `favicon.ico`, `apple-touch-icon.png`

The page ships with zero raster assets. Anything added here should be
compressed (SVGO for vectors, WebP or AVIF for photography) and given
explicit `width` and `height` attributes to avoid layout shift.
